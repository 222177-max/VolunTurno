# VolunTurno

Sistema web para la gestión de turnos y voluntarios en organizaciones comunitarias.

## Tecnologías

- Frontend: Astro 6 y Tailwind CSS 4
- Backend: Node.js 24 y Express
- Base de datos: MySQL
- Puerto frontend: 4321
- Puerto backend: 3006

## Funcionalidades

- Inicio de sesión y autenticación
- Panel de coordinador
- Calendario de turnos
- Creación y publicación de turnos
- Gestión de borradores
- Componente de confirmación multimodal
- Interfaces accesibles

## Ejecución local

Frontend:
cd frontend
npm install
npm run dev

Backend:
cd backend
npm install
node src/server.mjs

Para conectar MySQL es necesario configurar las variables de entorno del backend.
No se incluyen credenciales privadas en el repositorio.
